# M5Burner listing – LG TV Remote

## Name

LG TV Remote

## Short description (one line)

Magic-Remote-style controller for LG webOS TVs: Wi-Fi pointer and typing, IR, Bluetooth and USB.

## Description

Turn your Cardputer into a remote for LG webOS TVs.

- **Wi-Fi remote** – pairs with the TV over your home network (webOS second-screen API):
  pointer/cursor, typing straight into TV text fields, app launcher, volume level.
  Keys fall back to infrared automatically when the TV is not reachable.
- **IR remote** – works with every LG TV out of the box, also while the TV is off.
- **Air mouse** – on the Cardputer ADV the motion sensor moves the cursor like a Magic Remote;
  on both models the arrow keys move it too.
- **Bluetooth** (webOS 5+) and **USB cable** modes – keyboard + mouse + media keys.
- Guided first-run setup for every mode, colour-coded remote screens, status light (RGB LED).
- Settings backup on the SD card (`/config/lgtv-remote/settings.json`), so updates keep the pairing.

Keys: arrows `; . , /`, `enter` OK, `del` Back, `h` Home, `= -` volume, `[ ]` channel,
`a` pointer, `t` type text, `l` apps, `TAB` help, `OPT` app menu.

Works on M5Stack Cardputer and Cardputer ADV. Install with M5Burner or M5Launcher.
Open source (MIT) – author: Patryk Strzelecki.
